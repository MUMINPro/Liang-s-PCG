# Sebastian Lague 程序化地形生成 学习总结（第 1–5 集）

> 这份总结覆盖了你跟着 Sebastian Lague《Procedural Landmass Generation》第 1–5 集学到的全部核心知识，按"原理 → 代码 → 易错点"的脉络整理，方便日后回顾。

## 一、整体架构：四个脚本各管一摊

整个系统采用"职责分离"的设计，每个脚本只做一件事：

| 脚本 | 职责 | 类型 |
|------|------|------|
| `Noise` | 生成柏林噪声高度图（纯数学，不碰 Unity 渲染） | 静态工具类 |
| `MeshGenerator` | 把高度图转成网格数据（顶点+三角形+UV） | 静态工具类 |
| `TextureGenerator` | 把数据转成贴图 | 静态工具类 |
| `MapDisplay` | 把网格和贴图显示到场景里 | MonoBehaviour |
| `MapGenerator` | 总协调：调用上面各模块，串起整个流程 | MonoBehaviour |

数据流向：

```
MapGenerator.GenerateMap()
   │
   ├─ Noise.GenerateNoiseMap()        → 高度图 float[,]
   ├─ 根据 regions 生成颜色数组 Color[]
   │
   └─ 根据 DrawMode 选择显示方式：
        ├─ NoiseMap  → 黑白噪声贴图
        ├─ ColorMap  → 彩色地形贴图（平面）
        └─ MeshMap   → 3D 网格地形
```

## 二、柏林噪声（Perlin Noise）

### 核心特性

`Mathf.PerlinNoise(x, y)` 返回 `[0, 1]` 之间的值。它和普通随机数的关键区别：**相邻位置的值很接近，平滑过渡**，适合做地形、云朵、火焰等自然形态。

### 为什么坐标要除以 scale

`Mathf.PerlinNoise` 在整数坐标上返回固定值（约 0.5），所以必须用小数坐标采样：

```csharp
float sampleX = x / scale;
```

- `scale` 小 → 采样跨度大 → 地形崎岖
- `scale` 大 → 采样跨度小 → 地形平缓

类比：在一座山上空飞行，飞得低看到每块石头（崎岖），飞得高只看到大致山形（平缓）。

## 三、多八度噪声（Octaves）

单层噪声太"光滑"，缺少细节。真实地形是大轮廓 + 中等起伏 + 小细节的叠加，所以把多层不同频率/振幅的噪声叠起来，每一层叫一个"八度"。

### 三大参数

| 参数 | 控制什么 | 典型值 | 效果 |
|------|---------|--------|------|
| `octaves` | 叠加几层 | 4 | 越多细节越丰富 |
| `persistance` | 每层**振幅**衰减速度（影响力） | 0.5 | 越大越粗糙；为 0 时只有第一层有效 |
| `lacunarity` | 每层**频率**增长速度（细节密度） | 2 | 越大层次越分明；为 1 时多层失去意义 |

音乐类比：persistance 像音量旋钮（每层八度的响度），lacunarity 像音高跳跃（每层八度的频率跨度）。

### 叠加逻辑

```csharp
float amplitude = 1;     // 每个像素重置
float frequency = 1;
float noiseHeight = 0;

for (int i = 0; i < octaves; i++) {
    float sampleX = (x - halfWidth) / scale * frequency + octaveOffsets[i].x;
    float sampleY = (y - halfHeight) / scale * frequency + octaveOffsets[i].y;

    float perlinValue = Mathf.PerlinNoise(sampleX, sampleY) * 2 - 1;  // 关键：* 2 - 1
    noiseHeight += perlinValue * amplitude;

    amplitude *= persistance;   // 振幅递减（1 → 0.5 → 0.25 ...）
    frequency *= lacunarity;    // 频率递增（1 → 2 → 4 ...）
}
```

### 关键点 1：`* 2 - 1` 的作用

把噪声从 `[0, 1]` 变成 `[-1, 1]`，让叠加时**有正有负**。否则全是正数，多层累加只会越来越高，地形"飘在空中"没有低谷。

### 关键点 2：amplitude 声明位置

`amplitude = 1` 写在**像素循环里、octave 循环外**——每个像素重置为 1，但在 octave 循环内反复 `*= persistance` 逐层递减。这就是"每层权重递减"的来源。

## 四、归一化（Normalization）

多层叠加后 `noiseHeight` 范围不可控（可能 -3 ~ 3），但显示和着色需要 `[0, 1]`。所以：

### 第一遍循环：边算边记录最值

```csharp
float maxNoiseHeight = float.MinValue;  // 故意设成极小，保证任何值都更大
float minNoiseHeight = float.MaxValue;  // 故意设成极大，保证任何值都更小

// 循环里：
if (noiseHeight > maxNoiseHeight) maxNoiseHeight = noiseHeight;
else if (noiseHeight < minNoiseHeight) minNoiseHeight = noiseHeight;
```

> "找最值"的经典套路：找最大值就把初值设成最小，找最小值就设成最大。

### 第二遍循环：映射到 [0, 1]

```csharp
noiseMap[x, y] = Mathf.InverseLerp(minNoiseHeight, maxNoiseHeight, noiseMap[x, y]);
```

`InverseLerp(a, b, value)` 返回 value 在 [a, b] 区间里的相对位置（0~1）。最低点→0，最高点→1。

## 五、可复现的随机：System.Random + 种子

### 为什么用 System.Random 而不是 UnityEngine.Random

| | UnityEngine.Random | System.Random |
|---|--------------------|---------------|
| 调用方式 | 静态，直接用 | 要 new 实例 |
| 种子控制 | 全局（影响所有地方） | 实例独立 |
| 适用场景 | 游戏内随机 | **可复现的生成（地图种子）** |

地形生成必须用 `System.Random`，才能保证"同一个种子 = 同一张地图"（像 Minecraft 的世界种子）。

### 八度偏移（octave offsets）

```csharp
System.Random prng = new System.Random(seed);
Vector2[] octaveOffsets = new Vector2[octaves];
for (int i = 0; i < octaves; i++) {
    float offsetX = prng.Next(-100000, 100000) + offset.x;
    float offsetY = prng.Next(-100000, 100000) + offset.y;
    octaveOffsets[i] = new Vector2(offsetX, offsetY);
}
```

给每层一个随机偏移，让各层采样不同区域；`offset.x/y` 是 UI 可控的额外偏移，可以手动平移地图。

## 六、以中心缩放 / 居中

### 噪声采样以中心缩放

```csharp
float halfWidth = mapWidth / 2.0f;
float sampleX = (x - halfWidth) / scale * frequency + ...;
```

减去 `halfWidth` 让中心点采样坐标变成 0，调 scale 时地图围绕**中心**缩放，而不是围绕左下角。

### 网格顶点居中

```csharp
float topLeftX = (width - 1) / -2f;   // 负数 + 加号
float topLeftZ = (height - 1) / 2f;   // 正数 + 减号

vertices[i] = new Vector3(topLeftX + x, height, topLeftZ - y);
```

- **X 用加号**：数组 x 方向和 3D 世界 X 方向天然一致
- **Z 用减号**：数组从上往下遍历，但 3D 世界前方是 Z 正方向，需要翻转

本质都是"改变坐标系原点，让特殊位置对齐到 0"。

## 七、网格生成（Mesh）

### 关键数据结构

3D 模型 = 一堆三角形。描述一个网格需要：

- **vertices**（`Vector3[]`）：所有顶点的 3D 位置
- **triangles**（`int[]`）：三角形的顶点连接顺序（存的是顶点下标）
- **uvs**（`Vector2[]`）：每个顶点对应贴图上的位置（0~1）

### 数组大小怎么算

```csharp
vertices = new Vector3[meshWidth * meshHeight];               // 顶点数 = 宽×高
uvs      = new Vector2[meshWidth * meshHeight];               // 每个顶点一个 UV
triangles = new int[(meshWidth-1) * (meshHeight-1) * 6];      // 方格数 × 6
```

`triangles` 大小推导：W×H 顶点网格 = (W-1)×(H-1) 个方格，每个方格 2 个三角形，每个三角形 3 个顶点下标 → ×6。

### 把 2D 高度图变成 3D 顶点（核心一行）

```csharp
meshData.vertices[vertexIndex] = new Vector3(topLeftX + x, heightMap[x, y], topLeftZ - y);
//                                            ↑ X=横向     ↑ Y=高度（噪声）  ↑ Z=纵向
```

注意 Unity 坐标系：地形铺在 XZ 平面，**Y 是垂直方向（高度）**。所以高度值放在 Y，数组的 y 放在 Z。

### UV 计算

```csharp
meshData.uvs[vertexIndex] = new Vector2(x / (float)(width - 1), y / (float)(height - 1));
```

- 用 `(float)` 强转避免整数除法（否则结果全是 0 或 1）
- 用 `width - 1` 让最后一个顶点 UV 正好是 1（Sebastian 原版用 `width`，略不严谨）

### 三角形连接

```csharp
if (x < width - 1 && y < height - 1) {  // 最右列、最下行没有右/下邻居，跳过
    meshData.AddTriangle(vertexIndex, vertexIndex + width + 1, vertexIndex + width);
    meshData.AddTriangle(vertexIndex + width + 1, vertexIndex, vertexIndex + 1);
}
```

每个顶点作为方格的"左上角"画两个三角形，共享对角线拼成一个方格。**顶点顺序（绕向）决定正反面**——顺序错了会被背面剔除而看不见。

### AddTriangle 与 triangleIndex

```csharp
public void AddTriangle(int a, int b, int c) {
    triangles[triangleIndex] = a;
    triangles[triangleIndex + 1] = b;
    triangles[triangleIndex + 2] = c;
    triangleIndex += 3;
}
```

因为 `triangles` 是固定大小数组（不像 List 能 Add），用 `triangleIndex` 跟踪写入位置。数组比 List 性能更好，代价是要手动维护下标。

### CreateMesh：转成 Unity 能渲染的 Mesh

```csharp
public Mesh CreateMesh() {
    Mesh mesh = new Mesh();
    mesh.vertices = vertices;
    mesh.triangles = triangles;
    mesh.uv = uvs;
    mesh.RecalculateNormals();  // 计算法线，光照需要
    return mesh;
}
```

`MeshData` 是普通数据容器（可在子线程算），`Mesh` 是 Unity 渲染对象（只能主线程创建）。这种分离为后续多线程地形生成铺路。

`RecalculateNormals()`：根据三角形自动算每个顶点的法线（朝向），决定光照明暗。

## 八、显示：MeshFilter + MeshRenderer

```csharp
public void DrawMesh(MeshData meshData, Texture2D texture) {
    meshFilter.sharedMesh = meshData.CreateMesh();           // 装"形状"
    meshRenderer.sharedMaterial.SetTexture("_BaseMap", texture);  // 装"颜色"（URP写法）
}
```

| 组件 | 职责 |
|------|------|
| `MeshFilter` | 存网格数据（形状）——决定"长什么样" |
| `MeshRenderer` | 渲染（材质、贴图、光照）——决定"用什么画出来" |

要点：

- 用 `sharedMesh` / `sharedMaterial`（不是 `mesh` / `material`），因为要在**编辑模式**下预览，避免产生副本和警告
- **URP 设贴图用 `SetTexture("_BaseMap", texture)`**，旧的内置管线才用 `material.mainTexture`

## 九、编辑器扩展：自定义 Inspector

```csharp
[CustomEditor(typeof(MapGenerator))]
public class MapGeneratorEditor : Editor {
    public override void OnInspectorGUI() {
        MapGenerator mapGen = (MapGenerator)target;

        if (DrawDefaultInspector()) {       // 画字段 + 检测修改
            if (mapGen.autoUpdate)
                mapGen.GenerateMap();        // 改值就自动重新生成
        }

        if (GUILayout.Button("Generate")) {  // 手动生成按钮
            mapGen.GenerateMap();
        }
    }
}
```

要点：

- `Editor` 类必须放在名为 `Editor` 的文件夹里（不会被打包进游戏）
- `override`：重写父类的 `OnInspectorGUI`，没有它按钮不会显示
- `DrawDefaultInspector()` 返回 true 表示字段被修改了（Unity 按需重绘，只在值真变化时返回 true）

## 十、踩过的坑（重要经验）

| 坑 | 原因 | 解决 |
|----|------|------|
| 整张图变黑 | 找最大值用了 `<` 而非 `>` | 改成 `>`，max/min 逻辑要对 |
| 循环越界 | 变量名和上限不匹配（`x` 配 `mapHeight`） | x 配 width，y 配 height |
| Ctrl+S 后变白/灰 | 编译时字段被重置成默认值 0，生成了非法网格 | 给字段加默认值 + GenerateMap 里加参数保护 |
| Octaves=16 变灰 | 频率指数级增长（2^15），坐标过大导致 PerlinNoise 退化 | octaves 控制在 4~6，用 `[Range]` 限制 |
| 改成 1000×1000 变细长条 | 超过单 Mesh 上限 65535 顶点，索引溢出 | 尺寸控制在 ≤240，大地图要分 chunk |
| Mesh 显示纯白 | URP 用了错误的属性名 / `SetTexture` 少传参数 | `SetTexture("_BaseMap", texture)` 两个参数 |

### 防御性代码模板

```csharp
public void GenerateMap() {
    if (mapWidth <= 0 || mapHeight <= 0 || octaves <= 0) return;  // 参数保护
    // ...
    MapDisplay mapDisplay = FindObjectOfType<MapDisplay>();
    if (mapDisplay != null) { /* ... */ }
}

private void OnValidate() {   // Inspector 改值时自动校验
    if (mapWidth < 1) mapWidth = 1;
    if (mapHeight < 1) mapHeight = 1;
    if (octaves < 0) octaves = 0;
    if (lacunarity < 1) lacunarity = 1;
}
```

## 十一、C# / Unity 语法笔记

| 概念 | 要点 |
|------|------|
| `public static float[,] 方法名(...)` | 这是**方法**（有括号），不是变量；`float[,]` 是二维数组返回值 |
| `MonoBehaviour` | 让脚本变成 Unity 组件的"通行证"；纯工具类（static）不需要它 |
| `class` vs `struct` | class 是引用类型（共享），struct 是值类型（复制）；纯数据容器用 struct |
| `[System.Serializable]` | 让自定义类能在 Inspector 显示并随场景保存 |
| `[Range(0,1)]` | 让 Inspector 字段变成限定范围的滑块 |
| `[CustomEditor]` / `Editor` | 自定义 Inspector 外观 |
| `override` / `virtual` | 子类重写父类方法 |
| `float.MinValue` / `MaxValue` | 找最值时的"哨兵初值" |
| `Mathf.InverseLerp` | 把值从 [a,b] 映射回 [0,1] |
| 一维模拟二维 | `index = y * width + x`（乘的是宽，加的是 x） |
