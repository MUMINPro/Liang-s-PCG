# 攀爬地图关卡设计参数表 v0.1

> 本表是整个地图生成系统的"宪法"。生成器的所有行为都由这里的参数驱动。
> 标 ⚙ 的是需要在游戏开发中实测调整的值；标 ❓ 的是需要你先拍板的设计决定。

---

## 1. 玩家能力模型（一切设计的"尺子"）

关卡设计不直接用"米"做单位，而是用 **R（满体力连续攀爬距离）**。
这样以后改体力数值时，整套关卡设计自动跟着缩放，不用重调。

| 参数 | 默认值 | 说明 |
|---|---|---|
| 体力上限 | 100 | 抽象单位 |
| 攀爬消耗 | 5 / 米（垂直） | ⚙ 决定 R |
| **R = 满体力攀爬距离** | **20 米** | 派生值：100 ÷ 5 |
| 攀爬中跳跃消耗 | 12（一次性） | 跳跃是"昂贵的捷径" |
| 悬挂静止消耗 | 1 / 秒 | 不能无限挂着想路线 |
| 平地恢复速度 | 25 / 秒（约 4 秒回满） | 站上岩架就是奖励 |
| 营火 | 立即回满 + 存档 | 节奏阀门 |

**设计含义：** 一段 0.5R（10 米）的岩壁是"舒适"，0.7R 是"紧张"，
0.9R 是"必须一气呵成"，超过 1.0R 则必须借助道具、跳跃接力或中途小岩点。

---

## 2. 攀爬段类型词汇表（= 你未来的模块库分类）

每种类型对应一类你要建模的模块。消耗倍率作用于垂直距离。

| 边类型 | 消耗倍率 | 设计角色 |
|---|---|---|
| 行走段 | 0（恢复体力） | 喘息、看风景、捡东西 |
| 普通岩壁 | 1.0× | 主食 |
| 反斜面（悬垂） | 1.6× | 短而吓人，常作捷径 |
| 跳跃间隙 | 固定 12 / 次 | 节奏变化，失败惩罚高 |
| 藤蔓 / 绳索 | 0.5× | 引导性强的"高速路" |
| 洞穴穿越 | 1.0×（水平也计费） | 视觉遮蔽，氛围转换 |
| 岩柱跳跃链 | 12 × N | 连续跳跃挑战，奖励支线常用 |

❓ **待定边类型：** 滑坡（单向下行）、冰面（高山限定）——做不做？

## 3. 宏观结构

| 参数 | 默认值 | 说明 |
|---|---|---|
| 山体总爬升 | 450 米（≈ 22.5R） | ❓ 对应单局 1–2 小时 |
| 群系数量 | 4 + 峰顶 | ❓ 仿 PEAK 结构 |
| 营火 | 每个群系边界 1 个 + 大群系中部 1 个 | 共 5–7 个 |

### 群系分层（自下而上）

| 群系 | 海拔区间 | 主路径休息间距 | 每段营火区间的分支数 | 标志性威胁 | 主导边类型 |
|---|---|---|---|---|---|
| 海岸 | 0–15% | 0.3–0.45R | 2–3 | 无（教学区） | 行走、普通岩壁 |
| 丛林 | 15–40% | 0.4–0.6R | 2–4 | 毒物、湿滑 | 普通岩壁、藤蔓、洞穴 |
| 高山 | 40–65% | 0.55–0.75R | 1–3 | 寒冷（计时压力） | 普通岩壁、跳跃间隙 |
| 台地 | 65–90% | 0.65–0.85R | 1–2 | 强风（推力） | 反斜面、岩柱跳跃 |
| 峰顶 | 90–100% | 0.75–0.95R | 0–1 | 全部叠加 | 反斜面、跳跃 |

**难度曲线的本质就是这张表里"休息间距"那一列。** 其他一切（威胁、模块外观）都是包装。

## 4. 路线图拓扑规则（生成器的硬约束）

1. **主路径保底规则：** 主路径上任何一段攀爬的体力消耗 ≤ 0.85R（含类型倍率）。
   零道具、不跳跃接力即可登顶——道具让你更快，不是让你"可能"。
2. **分支三件套：** 每个营火段内的分支从以下类型抽取：
   - **捷径**：消耗 0.8–0.95R，跳过主路径 1 个节点（高手快感）
   - **安全迂回**：每段 ≤ 0.4R，但总路程 +50%（萌新保险）
   - **奖励支线**：死胡同，终点放行李/物资，深度 1–2 个节点
3. **汇合规则：** 所有分支最终汇回主路径；不存在"走错就死"的不可逆分叉。
4. **视线规则：** 每个营火节点应在生成时标记"地标朝向"——下一营火与峰顶
   的方向角，几何实现阶段保证该方向无遮挡（烟柱可见）。
5. **奖励守恒：** 每个营火段至少 1 个奖励支线；全图奖励支线数 = 营火段数 × 1.5（取整）。

---

## 5. 一张"好图"的验收指标（验证器的检查清单）

- [ ] 主路径每段消耗 ≤ 0.85R，全程总消耗在 18–28R 区间
- [ ] 主路径攀爬段数 30–45 段（决定时长）
- [ ] 无孤立节点、无不可达节点
- [ ] 每营火段分支数符合群系表
- [ ] 难度递增：各群系主路径平均消耗严格递增
- [ ] 营火间隔的预估游玩时间 8–15 分钟

---

## ❓ 需要你拍板的四个问题

1. **单局目标时长？** 我按 1–2 小时（4 人组队首通）设的 450 米，PEAK 大致也是这个量级。
2. **体力手感基准 R = 20 米**——即满体力能爬约 6–7 层楼高的墙。先按这个做原型？
3. **群系先做几个？** 建议原型期只做 2 个（海岸 + 丛林）打通管线，参数表留全。
4. **道具系统的野心？** 绳索/岩钉会显著改变路线设计（玩家能自创捷径）。
   建议 v1 只做"消耗品恢复体力"，路线改造类道具放 v2。
